# WorkTrackPro API

## Overview

WorkTrackPro is a full-stack web application built to help manage employees, their payments, work assignments, and statuses. It provides an admin panel for managing employee data, work-related tasks, payments, and HR roles, with integration to MongoDB for data storage.

## Features

1. **User Management**

2. **Work List**

3. **Payment Requests**

4. **Payment History**

5. **Employee Role Management**

6. **Success Payment Handling**

7. **Admin Dashboard**

8. **RESTful API (GET, POST, PATCH, DELETE)**

9. **MongoDB Integration**

10. **CORS Enabled**

## Setup Instructions

### Prerequisites

- Node.js (v16 or higher)
- MongoDB (MongoDB Atlas or a local MongoDB server)

### Database Structure

- **Users Collection**:
  - Stores user information such as email, name, role, verification status, etc.
- **Work List Collection**:
  - Stores work assignments for each employee, including the work name, date, and time spent.
- **Payment Request List**:
  - Stores payment request details made by HR for each employee, including month, year, and salary.
- **Payment Success List**:
  - Records the details of successful payments made to employees.

## Technologies Used

1. **Node.js**: JavaScript runtime for building the API.
2. **Express.js**: Web framework for building the server and routing.
3. **MongoDB**: NoSQL database for storing user, work, and payment data.
4. **CORS**: Middleware to enable cross-origin resource sharing.
5. **Axios**: HTTP client for making API requests from the client-side.
6. **Swal (SweetAlert2)**: For modal popups and confirmation dialogs.
